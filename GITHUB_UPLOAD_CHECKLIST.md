# GitHub Upload Checklist

## Repository Setup

### 1. Create GitHub Repository

**On GitHub:**
- [ ] Go to https://github.com/new
- [ ] Repository name: `luxtts-whisper-server` (suggested)
- [ ] Description: "OpenAI-compatible TTS/STT server for Apple Silicon — voice cloning + real-time transcription"
- [ ] Visibility: **Public** ⭐
- [ ] Initialize with: README (we'll replace with ours)
- [ ] Add .gitignore: Python
- [ ] Add license: MIT

### 2. Clone Repository Locally

```bash
cd ~
git clone https://github.com/YOUR_USERNAME/luxtts-whisper-server.git
cd luxtts-whisper-server
```

### 3. Prepare Files

**Copy from master package:**
```bash
# From the prepared master package
cp -r /path/to/luxtts-whisper-master/* ~/luxtts-whisper-server/
```

**Verify structure:**
```bash
ls -la ~/luxtts-whisper-server/
# Should see:
# - server.py
# - README.md
# - CHANGELOG.md
# - LICENSE (auto-generated by GitHub)
# - examples/
# - voices/
# - tts-output/
```

### 4. Clean Sensitive Data

**Remove (do NOT commit):**
- [ ] `__pycache__/` directories
- [ ] `.DS_Store` files
- [ ] `*.log` files
- [ ] Any personal voice samples
- [ ] Test output files

**Clean command:**
```bash
cd ~/luxtts-whisper-server
find . -name "__pycache__" -type d -exec rm -rf {} + 2>/dev/null
find . -name ".DS_Store" -delete
find . -name "*.log" -delete
rm -rf tts-output/*
```

### 5. Update Placeholder Paths

**In `server.py`, check for personal paths:**
```bash
grep -r "androsvale\|/Users/andros" . --include="*.py" 2>/dev/null
```

**Should see:** Only `~/voices/default_voice.wav` or generic paths.

**If needed, update:**
```python
# Default should be generic:
DEFAULT_VOICE = os.path.join(VOICES_DIR, 'default_voice.wav')
```

### 6. Commit and Push

```bash
cd ~/luxtts-whisper-server

# Initialize git (if not already)
git init

# Add all files
git add .

# Commit
git commit -m "Initial release: LuxTTS + Whisper MLX Server v1.0.1

- OpenAI-compatible TTS/STT endpoints
- Voice cloning with LuxTTS (~100x realtime)
- Real-time transcription with Whisper MLX
- Apple Silicon optimized (M1/M2/M3)
- Examples and documentation"

# Push to GitHub
git push origin main
```

## Security Checklist

Before making public, verify:

- [ ] **No API keys** in code
- [ ] **No personal paths** (usernames, home directories)
- [ ] **No private voice samples** included
- [ ] **No logs** with sensitive data
- [ ] **No `.env` files** with secrets
- [ ] **No SSH keys** or credentials

**Quick scan:**
```bash
cd ~/luxtts-whisper-server
grep -r "password\|secret\|key\|token" . --include="*.py" --include="*.sh" 2>/dev/null
```

Should return nothing sensitive.
